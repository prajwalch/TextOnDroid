# TextOnDroid

> [!NOTE]
>
> Work in progress expect bugs and missing features.

TextOnDroid is an extremely simple text editor for Android, built around a single, focused goal: editing basic text files.

It intentionally avoids features like syntax highlighting, code completion, and other advanced tooling to remain fast, lightweight, and distraction-free. All essential text editing operations like **open**, **close**, **save**, **save as**, **undo**, **redo**, as well as **find** and **replace** are supported. As a result, TextOnDroid is ideal for situations where you just want to quickly open a text file, make some changes, and save.
